# API coverage

MiniFugu implements **all 10 distinct HTTP method/path pairs** in Turbopuffer's [public OpenAPI description](https://github.com/turbopuffer/turbopuffer-openapi), checked on 2026-09-29. The specification describes single and multiquery on the same URL, so it has 11 operation entries. The [metadata API documentation](https://turbopuffer.com/docs/metadata) also describes a `PATCH` route that is absent from that OpenAPI description; MiniFugu implements its `read_only` setting. OpenAPI route coverage is 100%; behavioral parity is not. MiniFugu is intended for small, synthetic local fixtures.

| Documented route | Supported behavior | Limits |
| --- | --- | --- |
| `GET /v1/namespaces` | Sorted namespace list, prefix and page size; live-compatible base64 pagination cursors, including a cursor on an exactly full final page and a null terminal cursor; malformed cursors are rejected | Local namespaces only; cloud continuation tokens are not generated |
| `GET /v1/namespaces/{name}/schema` | Returns the live service's normalized schema shape for supported attributes, including generated embedding vector fields | Unsupported schema features remain unavailable |
| `POST /v1/namespaces/{name}/schema` | Updates an existing schema, including supported text analysis options; object updates preserve omitted options and merge individual full-text settings, while string shorthand resets search options but retains filterability | Some advanced schema options are unavailable |
| `GET /v1/namespaces/{name}/metadata` | Schema with normalized embedding descriptors, row and byte estimates, durable timestamps, encryption and index fields | Byte counts are local estimates; index is always marked up to date; `encryption.sse` is a compatibility value and local snapshots are not encrypted |
| `PATCH /v1/namespaces/{name}/metadata` | Sets or clears `read_only`; metadata omits the field when false; setting persists and local branches/copies inherit it | `pinning` requires cloud compute and is rejected when non-null |
| `GET /v1/namespaces/{name}/hint_cache_warm` | Returns HTTP 202 and the documented acceptance body | Local scans need no cache warming |
| `POST /v1/namespaces/{name}/_debug/recall` | Runs exact vector searches with optional filters and ground truth | Recall is 1.0 for exact local search; sampling and index diagnostics differ |
| `POST /v2/namespaces/{name}` | Row/column upsert and patch, ID/filter deletes, conditions, affected IDs, schema, local copy/branch; duplicate explicit IDs reject the whole write, while filter-delete followed by an upsert may reuse an ID; dense and multi-vector patches are rejected while sparse-vector patches work; upserts supply every declared fixed vector; plain ID deletes count absent IDs as affected; null values remove attributes; partial filter flags complete all matching small local rows; backpressure flag accepted for upserts and ID deletes | Cross-account copy, service-style partial chunking, sharding and encryption configuration unavailable |
| `DELETE /v2/namespaces/{name}` | Deletes rows and schema, including durable data | Local persistence only |
| `POST /v2/namespaces/{name}/query` | Single/multiquery, filters, dense/sparse/multi-vector and BM25 ranking, numeric scoring, RRF, computed scores, text highlighting, Count/Sum aggregation with multi-attribute grouping and `ForEachUnique`, projection and limits | Server metrics and other advanced expressions unavailable |
| `POST /v2/namespaces/{name}/explain_query` | Validates and describes the local exact scan plan | Plan text describes MiniFugu, not Turbopuffer's distributed planner |

## Behavioral parity checks

These checks compare MiniFugu with **disposable, generated namespaces** on live Turbopuffer. They cover the listed inputs, not every possible value or option.

| Area | Compared behavior | Evidence |
| --- | --- | --- |
| Text analysis | BM25 matches across 13 analyzer configurations and 54 query strings, including tokenizer versions, stemming, stopwords, French, case sensitivity, ASCII folding and token length | [Captured live expectations](../tests/ranking.rs) in `text_analysis_matches_live_tokenization` |
| Highlighting | Returned fragments and offsets, ordering, limits and invalid options across 21 live cases | [Highlight fixture](../tests/fixtures/live_highlight.json) replayed by `highlights_match_the_live_service` |
| Schema responses | Normalized `GET /schema` and metadata schema entries for 23 attributes, including inferred fields and full-text defaults; generated embedding vectors and metadata embedding descriptors are checked separately. Partial object updates preserve existing search settings, nested full-text settings merge, and shorthand resets search options. ANN object forms, required top-level metrics, and metric mismatch errors were checked against disposable live namespaces. | [Schema fixture](../tests/fixtures/live_schema.json), [schema and ANN tests](../tests/http.rs), and [live differential test](../tests/differential.rs) |
| Namespace listing | Prefix and page-size results, exact encoded cursor values, invalid-cursor status, and terminal null cursor | [Namespace pagination test](../tests/http.rs) and disposable live namespace probes |
| Aggregations | `Count` and `Sum`, multiple group fields, one `ForEachUnique` on an array, null groups, empty `group_by`, float sum output, exact integer output above `2^53`, and rejected `id` or duplicate group fields | [Aggregation edge tests](../tests/http.rs) and [live differential test](../tests/differential.rs) |
| Query and write responses | Status, rows and order, `$dist` scores, computed BM25 scores, dense and sparse vector projections, aggregation values for 258 generated queries and 12 multiquery/RRF cases over six 12-row namespaces, including cosine and squared Euclidean vector metrics, nested filters, token sequences, prefixes, numeric ranking and filtered aggregation; nine successive write attempts per namespace and each resulting row snapshot, including rejected vector-omitting and duplicate-ID writes; schema updates and read-only metadata changes. Numeric scores use a relative tolerance of `1e-5` with an absolute floor of `1e-5`; a separate captured live fixture checks exact float32 output for selected BM25, dense/sparse vector, RRF and numeric-rank scores | [Seeded differential test](../tests/differential.rs) and [score precision regression](../tests/ranking.rs) |
| Errors | JSON error body; HTTP 400 for malformed JSON, zero single-query limits, wrong-type filter operands and common semantic errors; HTTP 422 for tested request-shape errors, including invalid offset types | [HTTP response tests](../tests/http.rs) and live probes |

For example, an empty `group_by: []` returns `aggregations`, just like an omitted `group_by`. A float `Sum` of zero stays `0.0`. Equal BM25 scores on integer IDs such as `5` and `11` return ID `5` first. These cases have local regression tests and were checked against live responses.

Additional live probes checked review edge cases: RRF accepts `vector_encoding`; missing `Dist` values are omitted from `Saturate`/`Decay` results; an extra argument on `Eq` returns HTTP 400; and decomposed accents under legacy `word_v0` tokenize the same way as MiniFugu. These observations keep the emulator's behavior aligned even where a generic validation or Unicode rule might suggest a different result.

Sparse KNN, fuzzy filtering, byte fields, numeric ranking, `Max` floors and default filterability are exercised against disposable synthetic namespaces in the optional [live compatibility test](../tests/compatibility.rs). Live probes also checked `read_only` write rejection and deletion, numeric ordering of filter-deleted IDs, absent-ID delete counts, null clearing and comparisons, string-array glob negation, `ForEachUnique` grouping, ID and attribute name boundaries, and last-write timestamps on branches. Multi-vector behavior is covered locally; the available development account rejects vector-array types as a gated feature, so live parity for that feature is unverified.

The optional [seeded differential test](../tests/differential.rs) runs only when `TURBOPUFFER_BASE_URL` and `TURBOPUFFER_API_KEY` are set. Run `cargo test --locked --test differential` to compare both services. It uses only generated rows and deletes its namespaces when finished. The normal suite replays the captured live expectations without an account. The differential comparison excludes billing, performance, and error text, which are service-specific or still differ.

API errors are JSON with `status` and `error`. Malformed JSON returns HTTP 400; recognized request shape errors, including invalid consistency levels and query option values, return HTTP 422; semantic validation errors generally return HTTP 400. MiniFugu deliberately rejects unknown write and query fields instead of silently accepting unsupported operations, which differs from some live endpoints. Error text, some metadata and response fields, and edge cases can differ. Compatibility tests never read application or customer records.
